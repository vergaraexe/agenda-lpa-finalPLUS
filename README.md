# Agenda LPA - version 1.5
Agenda diaria
- Hoja cuadriculada, dia + logo, lapiz / destacador / goma, grosores, formas inteligentes
- Fotos en miniatura sobre la hoja (mover, agrandar, recortar) y foto original en el Word
- UN Word por dia (AAAA-MM-DD.docx) que se actualiza solo (4 s despues de cada cambio); copia en Documentos/Agenda
- Envio semanal por correo (domingo 20:00)
Modulo de actas (independiente de la agenda)
- Boton "Acta" en la barra lateral: muestra el formato ACTA_GENERAL (2 hojas carta) y se escribe/firma con el lapiz
- Borrador guardado automaticamente; "Finalizar y enviar acta" genera PDF carta y lo envia al correo configurado
- Copias finalizadas: "Actas finalizadas" y Documentos/Actas
Icono: logo del engranaje LPA
